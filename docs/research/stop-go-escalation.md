# Stop, continue and attribution rules

Continue ordinary internal work across tests, checkpoints and workstream boundaries without additional author approval. A deterministic code or document defect is repaired locally, its downstream locks invalidated, and the affected tests rerun. Retain the failed fixture and repair record.

Stop the affected learner for oracle disagreement, malformed semantic/token ABI, config/source hash mismatch, corrupt checkpoint, unexpected model identity, forbidden assistance, sealed leakage, paid-resource requirement without authority, or durability failure after bounded reconciliation. Do not discard unaffected publication, documentation or code work. The package's external durability policy still requires complete recoverable Drive checkpoints at most ten minutes apart while dirty.

At the end of SYS: a positive primary signal opens representation/curriculum/precision attribution; an ordinary-accuracy-only gain opens shortcut diagnosis; baseline competence with a narrow null weakens the tested system; both learners incompetent opens harness diagnosis. A generic schema match weakens donor specificity, not all explicit representation. A coherent negative result is a publishable research output, not a reason to erase ambitious hypotheses from the earlier manuscript.

No automatic escalation from a small local pedagogue to a frontier intervention model. Research-plane authoring may consult strong models within existing authorized capacity, but intervention-plane substitutions require a new condition and cost record. No experimental failure authorizes paid training or public deployment.
